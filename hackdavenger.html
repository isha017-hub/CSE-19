About HeatBridge

A concept platform for identifying possible industrial waste heat reuse opportunities.

Problem

Industries often release excess heat into the environment. Nearby industries may need heat, but information about available heat and demand is not always connected.

Our Solution

HeatBridge provides a simple interface to register heat sources and heat demands, then generates possible matches using basic feasibility rules.

Matching Parameters

  • Temperature compatibility
  • Available and required capacity
  • Operating hours
  • Location similarity

Technology Used

  • HTML
  • CSS
  • JavaScript
  • LocalStorage
  • Rule-based matching
